# Reel copywriting

## Golden rule
The voice is the script. **Never put claims in the video that the speaker did not say** (prices, guarantees, medical claims, reviews). On-screen text *distils* what is said; it doesn't invent.

## On-screen text from speech
- Headline = 1–5 words: the core of the beat ("تشققات كبار", "70%", "توصيل 58 ولاية").
- Prefer nouns, numbers and strong verbs. Drop fillers.
- Keep the speaker's language/dialect and spelling style.
- Highlight 1 keyword per caption line (color/scale), never more than 2.

## Hooks (first 1.5 s)
Patterns: question ("واش تعرف علاش…؟"), bold claim, number shock ("3 أخطاء…"), pain ("سنانك يوجعوك كي تشرب البارد؟"), curiosity gap ("السر لي ما يقولوهلكش…"), direct callout ("يا صحاب المحلات…").
Visual hook must match: biggest type of the video, fastest motion, impact SFX.

## Product-ad structure (direct response)
1. Hook (pain or desire) — 0–2 s
2. Problem / situation — 2–6 s
3. Product reveal (hero shot) — 6–9 s
4. 3 benefits (one per beat, each with a callout on the product) — 9–20 s
5. Proof (only real: demo footage, numbers the user gave, real reviews) — optional
6. Offer: price (old → new if given), delivery (e.g. 58 ولاية), cash on delivery, stock/urgency only if true
7. CTA: one action ("اطلب دروك"، "ابعثلنا رسالة"، "اضغط على الرابط") + phone/handle on the end card
Generate up to 3 hook variants for A/B tests when asked.

## Platform-ready rules
- Facebook/Instagram ads: avoid "before/after body" claims, personal-attribute phrasing ("are you fat?"), and unverified health claims — they get rejected.
- Keep text inside safe zones; key info must be readable without sound (captions on by default for ads).

## UI copy for the platform itself
- Arabic-first, friendly, clear, short. Use Algerian-friendly Modern Standard Arabic for UI, Darija only for playful micro-copy.
- Buttons are verbs: "ابدأ"، "ولّد الفيديو"، "صدّر"، "جرّب ستايل آخر".
